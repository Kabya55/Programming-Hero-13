### 🚀 Premium Digital Tools Store

This is a modern and fully responsive digital product store built using React and Tailwind CSS. The goal of this project is to create a clean and user-friendly platform where users can easily explore premium tools and manage their shopping experience smoothly.

---

### 🛠️ Technologies Used

- ⚛️ React.js (Hooks, Props, Suspense API)
- 🎨 Tailwind CSS (Custom Gradients & Shadows)
- 🌼 DaisyUI (UI Components)
- 📜 JavaScript (ES6+)
- 🔔 React Toastify (Notifications)
- 📦 JSON (Dynamic Data Handling)

---

### ✨ Key Features

🔹 Dynamic Product Grid

- Products are loaded dynamically from a JSON file
- Tags like **Popular**, **New**, and **Best Seller**
- Easy to update and scale

---

### 🛒 Interactive Shopping Cart

- Add products with one click
- 🔢 Real-time total price calculation
- 🚫 Duplicate item prevention with warning alerts

---

### 🎯 Smooth User Experience

- ✨ 3D hover animations on product cards
- ⚡ Instant feedback with toast notifications
- 📱 Fully responsive design
