The spread operator is a syntax in JavaScript that allows an iterable such as an array or string to be expanded in places where zero or more arguments (for function calls) or elements (for array literals) are expected. It is denoted by three consecutive dots (...).

map(): map() is an array method that operates on each element of an array and returns a new array but does not modify the original array.

filter(): filter() is an array method that selects some elements from an array based on a condition and returns a new array.

forEach(): forEach() is an array method that loops over each element of the array, but does not return a new array.
